# Project status

CratonVM executes authentic OpenJDK class libraries as its foundational
architecture. The launcher uses `--real-jdk` by default; `--compatible` enables
the startup and throughput optimization layer. Both target HotSpot behavior.

See the [feature status index](docs/feature-designs/README.md) for implemented
capabilities and limits, [known issues](docs/known-issues/) for actionable gaps
and accepted limitations, and [release readiness](docs/RELEASE_READINESS.md)
for the checks required before distribution. Proposals and delivery history
are kept in the local internal archive.
