# `$`) is a class; `module <name>` is a module descriptor. `#` comments and
# blank lines are ignored. Order here does not matter — the generator sorts.

# needs it, and the denominator that sweep measured. Adding a class here without
# naming the guard it serves grows the baseline set without closing anything.
