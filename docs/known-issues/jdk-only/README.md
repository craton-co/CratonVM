# JDK-Only Known Issues & TODOs

> **Project Memory Convention**: In docs/known-issues/ are TODO pages and known external gaps that cannot be resolved within CratonVM (e.g., absence of TLS 1.1 in rustls, or unexecutable wave lane predictions).
>
> Active JDK-only designs, investigations, and working issues cited by source code have been moved one level above to [docs/jdk-only/](../../jdk-only/).
>
> Once an issue or bug is fixed and verified against a binary, its document moves under docs/internal/jdk-only/.

## Remaining Records

> The files remaining in this directory represent:
> - **Wave Predictions**: E/F/G/H wave lanes contractually forbidden to build or execute on binary that await verification against a binary.
> - **External Dependencies & Unaddressable Gaps**: Gaps resulting from upstream library contracts or unsupported legacy protocols.
> - **Open Nominations & Residuals**: Investigations with remaining open items awaiting future passes.
