## How to read a page

- The file name gives the wave that filed it (`i<wave>`), the lane (`L1`-`L7`, or `orch` for the orchestrator), and whether it is a defect or a `-proposal-`.
- Each wave that worked on a page appended a `## Wave N` section; the first status word of the last such section is the current status:
  - **OPEN**: work remains; the section says what and where.
  - **SWITCH-OFF**: built behind a default-off switch, waiting for (or kept out by) triage.
  - **KEPT-OFF**: measured and kept off; the page stays because a later stage is still open.
  - **DONE / FIXED**: on by default; the page is waiting to be retired.
- Lanes by area: L1 debugger / JVMTI / JDWP, L2 JIT compile doors and field sites, L3 reflection and stack walks, L4 method handles / indy / VarHandles, L5 class loaders and define, L6 threads and virtual threads, L7 the interpreter core.
