# Targets in vm/tests that RUN when their prerequisites are present.
#
# `vm/tests/common/mod.rs` turns a missing `cratonvm` binary, JDK or Java
# fixture into an `eprintln!` + `return`, at which point cargo prints
# `test ... ok`. A whole suite can report green while executing none of its
# assertions -- and 95 of the 174 files in vm/tests use that helper.
#
# CRATONVM_REQUIRE_E2E=1 turns every such skip into a panic. The CI step that
# sets it iterates THIS file, and ci.yml's rule for joining is that a target
# is listed only after someone has run it against a real CratonVM binary.
#
# Regenerate with:
#   CRATONVM_BIN=<binary> JAVA_HOME=<jdk> bash tools/e2e-ratchet-survey.sh
# and move any target the survey reports as RUNS into the list below.
#
