## How to Update This File

Open a PR. Self-removals merge by lazy consensus. Additions require the
process described in
[GOVERNANCE.md](GOVERNANCE.md#becoming-a-maintainer). The Steward will
synchronise the `@craton-co/cratonvm-maintainers` GitHub team with this file
after merge.
