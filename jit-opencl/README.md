# CratonVM OpenCL backend

Optional GPU kernel lowering for the [CratonVM workspace](https://github.com/craton-co/CVM).
This crate is experimental and withheld from crates.io publication.

See the [OpenCL reference](../docs/gpu/opencl-backend.md) for the runtime, hardware,
and validation requirements. A host-only build does not establish device execution.
