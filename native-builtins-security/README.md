# cratonvm-native-builtins-security

JDK security and SunEC native pack for CratonVM.

Part of the [CratonVM](https://github.com/craton-co/CVM) Java Virtual Machine implemented from scratch in Rust.

## Scope

This crate provides separated compatibility primitives and cryptographic / security routines for CratonVM.
